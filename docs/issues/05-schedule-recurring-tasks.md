## What to build

Support recurring Tasks as distinct Occurrences with their own progress and completion. Let a user choose calendar-based, frequency-based, total-volume, or completion-based recurrence and configure what happens to a missed Occurrence.

## Acceptance criteria

- [ ] A user can create and edit a recurring Task with a recurrence rule and end condition.
- [ ] Each Occurrence has independent progress, Sessions, and completion state.
- [ ] Missed Occurrences expire by default; optional carry-forward follows the configured rule.
- [ ] Editing a recurring series supports this-and-future changes and an occurrence-only change.
- [ ] Timezone and daylight-saving behavior follow the user's configured calendar week and locale.
